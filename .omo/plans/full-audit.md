# Plan: Full Re-Architecture — open_web_catcher (`full-audit`)

planner: Prometheus · created: 2026-08-22 · approval: explicit ("write the plan")
evidence: `.omo/drafts/full-audit.md` (14 audit lanes, ~150 findings, IDs like `[DM-C1]` resolve there to exact file:line)

## Context

Open Web Catcher = FastAPI + LangGraph multi-agent streaming-evidence pipeline + Next.js 15 console. Audit found systemic failures: decorative migrations w/ silent create_all fallback ([DM-C2/C3]), backfill that persists nothing ([DM-C1]), split-brain memory across Postgres/SQLite/JSON with cross-process clobbering ([MEM-C1..C3]), structurally broken cancellation ([AGT-C1]), zero auth + arbitrary file write ([SEC-C2/C3]), unbounded payload persistence ([SCH-C1/C2]), frontend poll storms with O(N) recompute cascades and zero memoization/virtualization/TS ([FE-C*]), cost math that misprices cache/thinking tokens and forecasts nothing ([COST-*]), non-reproducible tests + near-empty CI ([TST-*]), duplicated dual browser stacks where puppeteer holds port-worthy features ([TOOL-P*]).

Owner mandates U1–U38 + design decisions D1–D16 are binding (see draft §User-added asks v1–v3, §Design decisions). This plan encodes them as decision-complete batches.

## Scope / Must-NOT-Have

IN: everything referenced by U7–U38 and W0–W13 below.
MUST-NOT-HAVE:
- Do NOT delete or modify `Report/`, `Report.zip`, `run-detail-email-output.png` contents (owner's thesis material) — gitignore only.
- No GraphRAG. No user-facing fingerprint/proxy config knobs (zero-config mandate D15). No captcha-solver provider integration — adapter interface only, off by default.
- No destructive DB change without an Alembic migration providing a forward path; never drop tables carrying evidence without archive step.
- Do NOT delete `tools/playwright/**`. Screenshots persist as blob/file refs only — no inline base64 in DB rows ([SCH-C1] lesson).
- No new polling interval anywhere in `web/`; SSE is the only live channel.
- No implementation beyond these batches; each batch closes only through its QA gate.
