\chapter*{Abstract}
This report presents the design and implementation of a multi-agent AI platform for collecting evidence from illegal streaming websites. The work was carried out during an internship at Soft Stars for the client beIN SPORTS. The objective was to build a system capable of visiting target websites, classifying their pages, extracting stream URLs and hosting infrastructure details, and producing structured, auditable evidence to support downstream legal and operational action.

The project evolved in two stages. The first stage used n8n as a rapid experimentation environment for validating prompts, browser interactions, and end-to-end workflow logic. The second stage replaced the prototype with a code-based platform built around FastAPI, Next.js, Puppeteer-driven browser tools, structured observability, short-term and long-term memory, and first-party evaluation tooling.

The final system routes each input URL through specialized agents for classification, landing-page exploration, hosting-page extraction, and embedded-player analysis. The platform includes provider lookup, runtime telemetry, cost tracking, and an operator console for monitoring live and historical runs. For deployment, the solution is containerized and prepared for Azure, with event-driven execution through Azure Container Apps Jobs and Azure Service Bus.
