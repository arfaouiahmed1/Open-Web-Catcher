\chapter*{Abstract}
This report presents the design and implementation of a multi-agent platform for collecting evidence from illegal streaming websites. The work was carried out during an internship at Soft Stars for the client beIN SPORTS. The practical objective was to inspect unstable websites, classify their pages, extract relevant hosting and stream information, identify infrastructure providers, and support downstream takedown actions with traceable evidence.

The report also positions this work relative to the company's existing stream scraper. That scraper already performs deterministic crawling, page classification, host-page inspection, embedded-player discovery, screenshot capture, final stream extraction, and infrastructure enrichment. The solution developed during the internship was therefore not intended to replace that production capability directly. Instead, it was designed as an agentic workflow that can serve as a complementary and more adaptive backup path when highly dynamic pages, noisy HTML and JavaScript, nested iframes, or unusual anti-bot conditions reduce the effectiveness of the main scraper.

The project evolved in two stages. The first stage relied on n8n and was valuable as a rapid experimentation environment for testing prompts, browser actions, and end-to-end workflow logic. The second stage replaced the visual prototype with a code-based platform built around FastAPI, Next.js, Puppeteer-driven browser tools, persistent observability, short-term and long-term memory, and first-party evaluation utilities. This transition improved maintainability, visibility, and cost control while preserving the lessons learned during the earlier n8n phase.

The final system uses a lightweight orchestrator to route each URL toward specialized agents for classification, landing-page exploration, hosting-page extraction, and embedded-player analysis. The platform also includes provider lookup, takedown email drafting, runtime telemetry, and an operator console for monitoring runs. For deployment, the solution is packaged as containers and prepared for Azure, with event-driven execution through Azure Container Apps Jobs and Azure Service Bus.
